Internet access and academic websites

Campus access and Clash Verge Rev

Clash Verge Rev is a proxy client for accessing international websites. Import a subscription and enable the system proxy so browsers and other apps that honor it can reach academic websites according to your routing rules. If GitHub downloads are unavailable, use the installer hosted on this site. Contact me for a subscription link.

For databases covered by the university's subscriptions, sign in through the library or the university's off-campus access portal.

Download for Windows x64 · v2.5.1

Setup steps and other versions
  1. Download the installer for your operating system and processor. Choose Windows x64 for most 64-bit Intel or AMD Windows PCs.
  2. Open Subscriptions, paste your subscription URL, select Import, and activate the imported profile. Keep the URL private because it usually contains a personal token.
  3. Choose a server and mode under Proxies, then enable System Proxy. Turn it off when you are done.

Google Search, Google Scholar, and GitHub

Google Search helps find vendor documentation, lab websites, and software error messages. Use quotation marks for exact phrases and site: to restrict results to one domain.

Google Scholar searches papers by title, author, or topic. Filter by year, use Cited by to find follow-up work, or open All versions to look for an accessible copy.

GitHub hosts source code and project instructions. Check the README and license. Use Releases for installers or Code → Download ZIP for source files.

Literature search and full text

Search by the full title when you have it, or resolve the DOI to reach the publication page. For a topic search, combine keywords and synonyms, then follow references and citations. Verify the authors, year, journal, and version before saving.

How to use arXiv

arXiv provides open access to preprints. Search by title, author, abstract, or arXiv ID. When you know the title, set the search field to Title. Open the record, select View PDF, and save it from the browser's PDF toolbar.

Sci-Hub

Paste the DOI or article URL into the search box and select Open. Check the title, authors, and version in the result.

Journal sites, open copies, and ResearchGate

If the publisher requires a subscription, use the university library or look for an open copy under Google Scholar's All versions. On ResearchGate, use Request full-text if the option is available. Before citing, check whether you have a preprint, an accepted manuscript, or the published version.

Reference management and research notes

Zotero · Reference manager

Use Zotero to collect and organize papers, manage PDF attachments and annotations, and insert citations and bibliographies while writing. Zotero Connector saves bibliographic records and available attachments from your browser.

  1. Install Zotero and the Zotero Connector for your browser.
  2. Open a paper's abstract or publisher page, click the Connector icon, and choose the collection.
  3. Check the saved record and attachment in Zotero. If the PDF was not saved automatically, drag a copy you obtained through an authorized source onto the item.

Using a language model in Zotero

Install llm-for-zotero, select a model provider in the add-on settings, and test the connection. Open a paper and ask a question in the sidebar. Check the original page, units, and context when working with equations, data, or conclusions. An external provider may receive selected document content. Read the data flow documentation before configuring it.

Research software and simulation

Numerical solvers and simulation

MATLAB · Numerical computing and data processing
Use it for matrix operations, equation solving, parameter sweeps, and plotting. CDUT students and staff can link their university email to a license through the university's software portal. University notice
Python · Scientific computing and automation
Use NumPy and SciPy for array operations, numerical integration, equation solving, and fitting. Python also helps automate batch processing of experimental data. Create a separate virtual environment for each project. Virtual environments
Mathematica · Symbolic and numerical computation
Simplify expressions, differentiate, integrate, and solve algebraic or differential equations. Press Shift + Enter to evaluate the current notebook cell. Official website
Ansys Lumerical FDTD · Time-domain electromagnetic simulation
Simulate light propagation and scattering with the finite-difference time-domain method. Extract transmission, reflection, and scattering spectra, as well as near-field maps for nanostructures. Ansys Optics documentation
COMSOL Multiphysics · Finite-element and multiphysics simulation
Model wave optics with finite elements or couple electromagnetic and thermal physics. Inspect field distributions, parameter sweeps, and derived values. COMSOL Learning Center

Supporting research tools

VS Code · Code editing and debugging
Organize project files, edit and debug Python, preview Markdown, and edit and build LaTeX projects with LaTeX Workshop. Official tutorial
Matplotlib · Scientific plotting
Plot spectra, scatter plots, heatmaps, and multi-panel figures from data in Python. Export PDF or SVG for manuscript layout. Matplotlib quick start
Blender · 3D modeling and illustrations
Model apparatus, samples, and optical paths. Set materials, lighting, and cameras to render a schematic illustration. Rendering manual
NetEase UU Remote · Remote access and desktop control
Connect to an authorized workstation to check simulation progress or operate software on it. Disconnect the session when finished. Official website

Optics references

RefractiveIndex.INFO

Choose a material category, material, and data source, then enter the wavelength in µm. Read the refractive index n and extinction coefficient k where available. Check the temperature, wavelength range, material form, and original reference. Some entries provide only n.
