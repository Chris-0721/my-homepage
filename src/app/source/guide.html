下载 Windows x64 安装包 · v2.5.1

配置步骤与其他版本
  1. 按系统和处理器架构下载安装包。常见的 Intel、AMD 64 位 Windows 电脑选择 Windows x64。
  2. 启动客户端，在「订阅」页粘贴订阅地址，点「导入」并选中导入的配置。订阅地址通常含个人令牌，请保存在自己的客户端中。
  3. 在「代理」页选择节点，从首页打开「系统代理」。使用完毕后可在同一处关闭。

Google 搜索、Google 学术和 GitHub

Google 搜索可找厂商文档、课题组页面和软件报错。输入关键词或报错原文，按需用引号限定完整短语，用 site: 限定域名。

Google 学术可按标题、作者或主题检索论文。结果页用年份筛选，点「被引用次数」追踪后续研究，点「所有版本」找可访问版本。

GitHub可查看项目源码和使用说明。先读仓库的 README 和许可证。要安装成品时找 Releases，要下载源码时用 Code → Download ZIP。

检索与获取全文

知道题名时先用完整标题查找，有 DOI 时可直接打开 DOI 对应的出版页面。按主题检索时，先组合核心术语和近义词，再沿参考文献和被引记录扩大范围。保存前核对作者、年份、期刊和论文版本。

如何使用 arXiv

arXiv 提供开放获取的预印本。首页搜索框支持题名、作者、摘要和 arXiv 编号。已有完整题名时，把搜索字段改为 Title。进入文章详情后点 View PDF，再用浏览器 PDF 工具栏保存。

Zotero 与科研笔记

安装 Zotero 和浏览器 Connector

  1. 从官方下载页安装 Zotero，再为当前浏览器安装 Zotero Connector。
  2. 打开文献的摘要页或出版社页面，点浏览器工具栏的 Connector 图标，选择目标分类并保存。
  3. 回到 Zotero，检查条目和附件。若 PDF 未自动保存，可把通过授权渠道取得的 PDF 拖到对应条目上。

在 Zotero 里使用大语言模型

安装 llm-for-zotero 后，在插件设置选择模型后端并测试连接。打开一条文献，在插件侧栏提出问题。涉及公式、数据或结论时，回到原文核对页码、单位和上下文。外部后端可能接收选定的文献内容，配置前先看数据流说明。

Obsidian

创建一个本地仓库，用 Markdown 写阅读笔记、实验记录和课题索引。把文献题名或 DOI 放在笔记里，再用双向链接连接相关概念。 Obsidian 帮助

科研 AI 与 Agent

常用操作是限定工作目录、说明输入与预期输出、检查结果和文件变更。引用、公式、代码结果和拟提交内容分别回到原始资料或运行环境复核。

WorkBuddy
打开工作区，选择需要处理的文件夹，描述输出格式；完成后打开生成文件检查。 腾讯官方入口
DeepSeek Harness
从官方入口安装桌面端或按仓库说明启动，选择项目目录后查看任务执行记录。 官方入口
ChatGPT（GPT）
新开对话，粘贴需要解释的公式、图注或报错，补充学科背景和需要的输出格式。 打开 ChatGPT

科研软件与仿真

MATLAB · 成都理工大学
进入学校正版软件管理与服务平台，找到 MATLAB，按校方步骤使用学校邮箱关联授权。安装完成后启动软件，检查许可证和所需工具箱。 校方通知
Python
安装 Python，检查解释器版本，再为项目创建虚拟环境。进入项目后按其依赖文件安装所需包。 虚拟环境文档
VS Code
用「打开文件夹」查看项目；Markdown 用预览功能，LaTeX 可装 LaTeX Workshop 并配置 TeX 发行版；运行 Python 前选择项目的解释器。 官方教程
Ansys Lumerical FDTD
打开项目后按几何、材料、源、仿真区域和监视器的顺序核对设置。运行后从监视器查看或导出结果。 Ansys Optics 文档
COMSOL Multiphysics
在模型树中检查物理接口和边界条件，构建网格后运行研究，再到「结果」或「派生值」查看输出。 COMSOL 学习中心
Mathematica
新建 Notebook，用 Shift + Enter 运行当前单元。在函数文档里确认参数、默认假设以及符号或数值求解的输出格式。 官方入口
Blender
在视图中添加和摆放对象，设置材质、灯光和相机，再从渲染菜单生成并保存图像。 渲染手册
网易 UU 远程
在控制端和获准使用的工作站安装客户端，登录后从设备列表选择目标。操作完成后断开会话。 网易官方入口

论文写作与汇报

LaTeX 与 Overleaf
从期刊模板或空白项目开始，将图片和 .bib 上传到项目。编辑主 .tex 文件，点 Recompile，核对图号、引用和编译日志。 Overleaf 入门
Word
用投稿模板或学校模板编辑正文。在 Zotero 选项卡插入引用，再生成参考文献表。 Zotero Word 插件文档
iSlide
安装后打开 PowerPoint 的 iSlide 选项卡，选中待调整的对象，使用对齐、分布或统一尺寸功能。 iSlide 官方入口

光学书签

RefractiveIndex.INFO

依次选择材料类别、材料和数据来源，输入以 µm 为单位的波长。读取条目提供的折射率 n 和消光系数 k，核对温度、波段、材料形态和参考文献。有些条目只给出 n。
